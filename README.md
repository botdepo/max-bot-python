# MAX-бот на Python (maxapi) — стартовый бот для botdepo

Небольшой, но настоящий бот-заметки: пришлите ему текст — он сохранит,
`/list` покажет заметки с кнопками удаления. Его удобно взять за основу
своего бота: здесь уже есть команды, кнопки, хранение данных и всё, что
нужно, чтобы бот работал на [botdepo](https://botdepo.ru).

## Запустить за минуту

1. Получите токен бота — в кабинете [business.max.ru](https://business.max.ru/self): создать бота (нужна организация, ИП или самозанятость) → после модерации токен появится в карточке бота.
2. Зарегистрируйтесь на [botdepo.ru](https://botdepo.ru) → «Новый бот».
3. В поле «Репозиторий» вставьте ссылку на этот репозиторий, в «Токен бота» — токен.
4. «Задеплоить». Через минуту бот отвечает.

## Сделать своего бота на его основе

1. Нажмите **Fork** вверху этой страницы — у вас появится своя копия.
2. В botdepo создайте бота со ссылкой на **свой форк** (если уже запустили
   этот репозиторий — удалите того бота: ссылку у существующего бота пока
   поменять нельзя, а один токен не может работать в двух ботах сразу).
3. Меняйте код в своей копии — прямо в браузере на GitHub или у себя на
   компьютере — и нажимайте «Передеплоить» в карточке бота.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `main.py` | бот: команды, кнопки, обработчики |
| `storage.py` | хранение заметок в SQLite в `/data` |
| `requirements.txt` | библиотеки — по одной на строку |
| `AGENTS.md` | правила для ИИ-ассистентов (Cursor, Claude, ChatGPT) |

## Как менять

**Добавить команду** — новый обработчик:

```python
@dp.message_created(Command("help"))
async def help_(event: MessageCreated) -> None:
    await event.message.answer("Я умею хранить заметки.")
```
Добавьте его **выше** обработчика `save` — maxapi берёт первый подходящий.

**Добавить библиотеку.** Новая библиотека → строка в `requirements.txt` (например `httpx`). Ставить библиотеки из кода
нельзя — только через этот файл.

**Сохранять данные.** Только в папку `/data` — она переживает перезапуски и
передеплои. Остальная файловая система бота только для чтения: файл,
записанный рядом с кодом, вызовет ошибку.

**Секреты** (ключи API, пароли) — не в код, а в «Переменные окружения» в
карточке бота на botdepo. В коде читайте их через `os.getenv("ИМЯ")` /
`process.env.ИМЯ`.

## Пишете с ИИ

В `AGENTS.md` описаны ограничения платформы — Cursor, Claude Code и другие
ассистенты читают его сами. Если пишете в чате (ChatGPT и т.п.), вставьте
содержимое `AGENTS.md` в начало разговора.

## Запустить у себя на компьютере

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
BOT_TOKEN=ваш_токен python main.py   # Windows: set BOT_TOKEN=ваш_токен && python main.py
```

Локально данные сохраняются в папку `data/` рядом с кодом. Не запускайте
бота одновременно у себя и на botdepo с одним токеном — сообщения
достанутся только одной из копий, и бот будет отвечать через раз.

## Если что-то не работает

Логи и подсказки по ошибкам — в карточке бота на botdepo. Разбор частых
ошибок — в [документации](https://botdepo.ru/docs#errors).
